How to read it

At a matched footprint the quantisation-axis methods (binary, PQ, RaBitQ) dominate the projection-axis ones (Matryoshka, PCA): bits beat dimensions. A one-bit code with a re-ranking pass is lossless at 32× compression on both embedders, and the larger embedding binarises better (92% vs 88%) because its information is spread across more coordinates. The benchmark measures quality retained per byte, not absolute quality, so a small embedder and a large one can be compared on the same axis.

Submit your method

The leaderboard is reproducible and open. To add a row:

  1. Register your method with the @method(...) decorator (see CONTRIBUTING.md).
  2. Run bitbudget run --embedder mxbai --corpus scifact nfcorpus arguana fiqa.
  3. Open a PR adding your row to site/data.json with the generated results card attached.

Every number on this page is regenerated from site/data.json and deployed automatically on merge. No servers, no tracking.
